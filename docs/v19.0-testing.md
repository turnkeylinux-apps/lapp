# LAPP 19.0 testing

## Scope and source decision

LAPP 19.0 uses Debian 13 Trixie packages for Apache, PHP, PostgreSQL,
Adminer, Composer, and the PHP, Python, and Perl PostgreSQL clients. Trixie
provides the application stack needed by the appliance, so no upstream
repository or downloaded application artifact is required. Webmin and its
Apache, PHP, and PostgreSQL modules continue to come from the signed TurnKey
Trixie repository.

The v18 plan named `postgresql-contrib` and `libapache2-mod-python`. Neither
package has a Trixie candidate. PostgreSQL 17 includes its formerly separate
contrib modules, while Python applications are supported through CGI and the
packaged PostgreSQL client libraries. Composer is explicitly installed from
Debian to match the documented development-helper contract.

The acceptance command is:

```sh
/sandboxed-git/turnkey/tools/test-v19-appliance lapp \
    --source /home/agent/.local/worktrees/turnkey-apps/lapp/wish-lapp-v19-trixie
```

It builds a Trixie root filesystem in TKLDev, imports the configured root into
Docker, starts the normal systemd init path with first-boot credentials, and
runs `tests/v19.sh`. The command's retained report under
`~/.local/state/turnkey-v19-harness/runs/lapp/` records the exact source and
harness commits, archive and tree hashes, installed versions, configured-root
mode, application evidence, updater evidence, cleanup result, and verdict.

## Updater check

`tests/v19.sh` runs `apt-get update` and checks eligible candidates for
`apache2`, `libapache2-mod-php`, `postgresql`, `adminer`, and `composer` with
`apt-cache policy`. It records the versions before the refresh and proves they
are unchanged afterward. A pass means APT accepted the signed Debian and
TurnKey Trixie metadata, each identity-defining package has an eligible
candidate, and no Bookworm source remains configured.

## Known limitation

The Docker acceptance path does not exercise the installer, kernel, bootloader,
or physical hardware. LAPP adds no appliance-specific behavior at those
boundaries, so the validated Core 19 baseline supplies that inherited evidence.

## Deferred issues

None found that affect normal supported LAPP use.
